# Wersja 6.1.0

## Opis wersji

Wersja 6.1.0 dopracowuje płatności wprowadzone w [wersji 6.0.0](versions/6.0.0.md#wersja-600), naprawia logowanie przez Google i ułatwia sprawdzenie działania GPS.

### Zmiany

* Dodano poradnik dla liderów drużyn
* Możesz przetestować lokalizację GPS, aby przed wydarzeniem upewnić się, że telefon poprawnie ustala pozycję
* Naprawiono logowanie przez konto Google
* Poprawiono komunikat po podaniu błędnych danych logowania
* Poprawiono działanie płatności
