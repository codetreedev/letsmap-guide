# Wersja 6.2.0

## Opis wersji

Wersja 6.2.0 ułatwia pracę z ofertami i przedmiotami oraz poprawia stabilność aplikacji.

### Zmiany

* Nowe ustawienie wydarzenia **Kto handluje w sklepie** – kupować i wystawiać oferty w imieniu drużyny może tylko lider albo każdy członek drużyny ([zobacz ustawienia wydarzenia](event-management/creating-event.md#sklep-i-oferty))
* W formularzach i filtrach ofert możesz wyszukiwać przedmioty, co ułatwia pracę przy ich dużej liczbie
* Przy wyborze obrazka przedmiotu dostępnych jest 146 nowych grafik o tematyce zamkowej
* Podczas płatności podajesz adres rozliczeniowy, a podatek naliczany jest automatycznie

### Poprawki

* Poprawiono działanie aplikacji przy otwartej klawiaturze
* Edycja wydarzenia nie usuwa już jego ustawień
* Naprawiono błąd listy przedmiotów
